# Repository Language Policy

All content maintained in this repository MUST be written in English.

This requirement applies to:

- Documentation, specifications, and contributor or agent instructions.
- Source code identifiers, comments, and documentation comments.
- Error messages, diagnostics, logs, and other user-facing text.
- Tests, examples, sample data, and configuration descriptions.
- File and directory names.

Write all new content in English. When updating existing non-English content, translate it into English while preserving its technical meaning and behavior.

Before completing a change, verify that all added or modified repository content follows this policy.
